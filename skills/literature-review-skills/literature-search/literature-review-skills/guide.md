# Literature Review Guide

This file stores advanced literature review guidance that goes beyond basic Zotero use and basic literature search.

## 1. Define key concepts early

Define the central concepts near the beginning of the review instead of leaving them vague. If a supervisor prefers definition-first writing, introduce the working definitions early and tie them directly to the research question rather than listing broad textbook meanings.

## 2. Prioritize stronger sources first

When building the reading list, prioritize sources in this order unless the user asks otherwise:

1. ABS 4 or above
2. ABDC A or above
3. Other top journals in the field
4. Very highly cited papers
5. Recent papers in strong journals when citation counts are still low

Do not treat all papers as equally useful. Anchor the review with the strongest and most influential papers first, then move to narrower, newer, or more contradictory sources.

## 3. Use citation chaining, not only keyword search

Use keyword search as the starting point, not the whole method.

After finding a strong seed paper, follow its reference list to identify foundational work. Then follow later papers that cite that seed paper when possible. This is often more reliable than relying only on broad keyword search.

If a paper is found through another paper's references, still verify that it truly supports the claim for which it will be cited.

## 4. Verify every paraphrase against the original paper

Never assume a paraphrase is safe just because it sounds plausible.

Before using a claim:

1. Read the paraphrased sentence carefully.
2. Return to the original source.
3. Check whether the source really contains that meaning.
4. Decide whether the support is full, partial, or absent.
5. Record the page number or exact location when possible.

Do not invent page numbers, quotations, or supporting claims. If a source only supports part of a sentence, narrow the sentence.

## 5. Use Zotero as a capture tool, not the final authority

If Zotero is available, use it to collect references efficiently, but always manually inspect imported metadata.

Check at least:

- author names
- year
- title capitalization
- journal title
- volume and issue
- page range
- DOI
- attachment quality

Treat imported metadata as provisional until checked.

## 6. Keep source quality and background evidence separate

Avoid using weak web pages, casual news coverage, or generic internet summaries as core academic references.

For background facts, prefer institutional or authoritative sources when needed, such as the World Bank, OECD, WHO, government reports, or official datasets. Keep these separate from the core peer-reviewed literature.

## 7. Draft the review as an argument, not a list of notes

The review should tell one coherent story. Do not stack disconnected summaries paragraph after paragraph.

Each paragraph should usually do one main job:

- introduce a theme or tension
- compare findings
- explain a mechanism
- identify a limitation
- set up the next section

Aim for paragraphs of about 4 to 6 sentences unless the genre clearly requires otherwise. Make the first sentence show the paragraph's point and the last sentence show why it matters for what comes next.

Prefer clear, readable sentences over long and overloaded ones.

## 8. Keep references consistent

Use one citation style consistently across in-text citations and the reference list.

When working in APA-style contexts:

- keep author-year formatting consistent
- keep title capitalization consistent
- preserve journal information accurately
- do not mix incomplete web references with formal journal entries

If the user already has a reference list draft, preserve verified entries where possible instead of reformatting everything from scratch.

## 9. Helpful working outputs

When helping with a literature review, prefer outputs that make the reasoning easy to audit:

- a ranked reading list
- a claim-to-source check table
- a paragraph outline by theme
- a drafted review section with clear transitions

When summarizing literature, distinguish clearly between:

- what the paper finds
- what the paper does not show
- what is inferred across papers

## 10. Hard boundaries

- Do not fabricate sources.
- Do not cite a paper for a claim that has not been checked.
- Do not let polished prose hide weak evidence.
